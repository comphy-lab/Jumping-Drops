# Jumping Drops Simulation - Quick Reference Guide

## TL;DR - What Changed?

**Old (Deprecated):**
- `JumpingDrops_legacy.c` - Local initialization with STL
- `JumpingDrops_Snellius_legacy.c` - HPC version (had missing gravity bug!)

**New (Use These):**
- `src-local/jumpingDrops_common.h` - Shared definitions
- `jumpingDrops_init.c` - Init phase (local, STL → dumpInit)
- `jumpingDrops_main.c` - Main phase (MPI-compatible)

**Key Fix:** Added missing `G.y = -Bo` in HPC version!

## Most Common Commands

### Local: Full Workflow
```bash
# Both init + main (default)
./runSimulation.sh default.params
```

### Local: Init Only
```bash
# Create dumpInit from STL
./runSimulation.sh --init-only default.params
```

### Local: Main with MPI
```bash
# Run with 8 cores
./runSimulation.sh --main-only --mpi --cores 8 default.params
```

### HPC: Complete Workflow
```bash
# 1. Local: Create initial condition
./runSimulation.sh --init-only case.params

# 2. Local: Transfer to HPC
scp simulationCases/1000/dumpInit hpc:Drop-Impact/simulationCases/1000/

# 3. HPC: Submit job
sbatch runSweepSnellius.sbatch
```

## Parameter File Template

```bash
# Required parameters
CaseNo=1000              # 4-digit case number
Oh=0.001                 # Ohnesorge number
Bo=0.001                 # Bond number
MAXlevel=10              # Max refinement level
tmax=10.0                # Simulation time
```

## File Execution Summary

| File | Purpose | MPI | Input | Output |
|------|---------|-----|-------|--------|
| `jumpingDrops_init.c` | Create IC | ❌ Serial only | STL file | dumpInit |
| `jumpingDrops_main.c` | Run sim | ✅ MPI-ready | dump/dumpInit | snapshots, log |

## Quick Troubleshooting

| Error | Cause | Fix |
|-------|-------|-----|
| "dump file not found" | No initial condition | Run `--init-only` first |
| "Cannot restore dump" | Corrupted dump | Re-run init phase |
| "Source file not found" | Missing files on HPC | Transfer all new .c/.h files |
| Init phase too slow | High MAXlevel | Expected - only run once |

## Shell Script Options

### runSimulation.sh
```bash
--init-only       # Init phase only
--main-only       # Main phase only
--mpi             # Enable MPI
--cores N         # Number of MPI cores (default: 4)
--compile-only    # Compile but don't run
--debug           # Debug mode (-g -DTRASH=1)
--verbose         # Verbose output
```

### runParameterSweep.sh
```bash
--skip-init       # Skip init for all cases
--dry-run         # Show combinations, don't run
--mpi             # Enable MPI for all cases
--cores N         # MPI cores per case
--compile-only    # Compile but don't run
--verbose         # Verbose output
```

## Common Workflows

### Single Case Development
```bash
# First time
./runSimulation.sh case.params

# Subsequent runs (skip init)
./runSimulation.sh --main-only case.params
```

### Parameter Sweep
```bash
# First sweep
./runParameterSweep.sh sweep.params

# Re-run after changes (skip init)
./runParameterSweep.sh --skip-init sweep.params
```

### HPC Large-Scale
```bash
# Local: Initialize all cases
./runParameterSweep.sh --init-only sweep.params

# Local: Transfer to HPC
rsync -av --include='**/dumpInit' --include='*/' --exclude='*' \
    simulationCases/ hpc:Drop-Impact/simulationCases/

# HPC: Run sweep
sbatch runSweepSnellius.sbatch
```

## What You Need on HPC

Minimum files per case directory:
```
simulationCases/<CaseNo>/
├── dumpInit              # From local init phase
└── case.params           # Generated by sweep
```

Auto-created by sbatch script:
```
simulationCases/<CaseNo>/
├── jumpingDrops_main.c     # Copied by script
├── jumpingDrops_main       # Compiled executable
└── intermediate/         # Created if needed
```

Shared header used during compilation:
```
src-local/jumpingDrops_common.h
```

## Performance Tips

1. **Init phase**: Run once locally, reuse dumpInit
2. **Main phase**: Use MPI on HPC for best performance
3. **Parameter sweeps**: Use `--skip-init` after first run
4. **Long runs**: Use restart files for fault tolerance
5. **Storage**: Clean up intermediate files after post-processing
